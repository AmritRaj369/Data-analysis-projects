# **SQL Data Analytics Repository**

This repository showcases my expertise in SQL for data analysis, reporting, and business intelligence. It includes well-structured SQL scripts demonstrating how I leverage relational databases to derive actionable insights, optimize queries, and create analytical solutions.

---

## **Key Highlights**

* **Database Exploration & Schema Understanding**

  * Queried `INFORMATION_SCHEMA` to profile database tables, columns, and data types.
  * Conducted **data profiling** to understand relationships, constraints, and missing values.

* **Data Cleaning & Preprocessing**

  * Applied SQL techniques to handle **NULL values**, outliers, and duplicate records.
  * Standardized data formats (dates, categories) to ensure **accuracy and consistency**.

* **Advanced Querying & KPIs**

  * Built **complex queries** using **JOINS, subqueries, and CTEs** to merge and analyze multi-table datasets.
  * Computed key metrics such as **total sales, revenue growth, AOV (Average Order Value), and customer lifetime value**.

* **Time-Series & Trend Analysis**

  * Used SQL **date functions** (`DATE_TRUNC`, `EXTRACT`, `DATEDIFF`) to evaluate **monthly/quarterly trends, seasonality**, and performance shifts.
  * Designed queries for **cumulative sums, moving averages, and YoY growth comparisons**.

* **Segmentation & Behavioral Analysis**

  * Implemented **CASE WHEN logic** to segment customers into cohorts (VIP, frequent, new) and products into categories (high-performing, low-performing).
  * Conducted **behavioral analysis** to identify churn patterns and revenue-driving segments.

* **Window Functions for Analytics**

  * Leveraged **`RANK()`, `DENSE_RANK()`, `LAG()`, `LEAD()`** for ranking top products, sales benchmarking, and tracking customer recency and frequency.

* **Reporting & BI Integration**

  * Created **SQL Views** for customer reports, sales dashboards, and product performance summaries.
  * Optimized SQL queries for fast retrieval and seamless integration with **Tableau and Power BI**.

* **Business Insights & Recommendations**

  * Delivered **data-backed insights** on sales trends, delivery performance, and customer engagement.
  * Built **part-to-whole contribution analysis** using window functions for Pareto-based reporting.
